# Renders

Every finished MP4 lives here, named `epNN-short-title-vN.mp4` (e.g. `ep03-find-your-purpose-v1.mp4`).
Stored with Git LFS (see `.gitattributes`). Rule: a render is not done until it is delivered to Jason AND pushed here.
Raw footage is also LFS-tracked (`*.mov`) so a lost session can never lose source again; keep it in `raw/epNN/`.
